# Array Looping Tasks

### Task 1

Write a JavaScript code to reverse the array `colors` **without using the `reverse()` method**.

**Input:**

```js
const colors = ['red', 'blue', 'green', 'yellow', 'orange'];
```

**Output:**

```js
['orange', 'yellow', 'green', 'blue', 'red']
```

---

### Task 2

Write a JavaScript code to get the even numbers from an array using any looping technique.

**Input:**

```js
const numbers = [12, 98, 5, 41, 23, 78, 46];
```

**Output:**

```js
[12, 98, 78, 46]
```

---

### Task 3

Use a `for...of` loop to concatenate all the elements of an array into a single string.

**Input:**

```js
var numbers = ['Tom', 'Tim', 'Tin', 'Tik'];
```

**Output:**

```js
'TomTimTinTik'
```

### Task 4 (Hard)

Reverse the words of a sentence. Only the **position of the words** will be reversed.

**Input:**

```js
const statement = 'I am a hard working person';
```

**Output:**

```js
'person working hard a am I'
```

### Task 5

Copy the given array into another array so that changing the copy does not affect the original array.

Change the first element of the copied array to `99`.

**Input:**

```js
[1, 2, 3]
```

**Expected Output:**

```text
Original: [1, 2, 3]
Copy: [99, 2, 3]
```

### Task 6

Given an array of student objects, print each student's name and marks.

**Input:**

```js
[
  { name: "John", marks: 85 },
  { name: "Alice", marks: 90 }
]
```

**Expected Output:**

```text
John scored 85
Alice scored 90
```

### Task 7

Given a 2D array, update the value at the **second row, first item** to `99` and print the updated array.

**Input:**

```js
[
  [1, 2],
  [3, 4],
  [5, 6]
]
```

**Expected Output:**

```js
[
  [1, 2],
  [99, 4],
```
